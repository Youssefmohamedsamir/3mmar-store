# متجر عمار للهواتف والإكسسوارات | 3mmar Store

مشروع متجر إلكتروني عصري ومتكامل للأجهزة الذكية والإكسسوارات، مصمم ومبرمج بأعلى معايير الـ **Clean Code** وأفضل أداء وأعلى درجات الحماية (**High Security & Performance**).

---

## مواصفات المشروع والتقنيات المستخدمة

- **الواجهة الأمامية (Frontend):** 
  - أحدث إصدارات **Angular** بمكونات مستقلة (Standalone Components & Signals).
  - تنسيق خارجي متكامل بدون استخدام أي إيموجي نهائياً (**Strictly No Emojis**)، مع الاعتماد الكامل على أيقونات **SVG** دقيقة واحترافية.
  - تصميم عصري بطابع السايبر والنيون المظلم المستوحى من هوية الشعار (**Cyber Dark Neon Theme**).
  - أنيميشن احترافي للشعار ثلاثي الأبعاد، مسح ليزري، وهالات ضوئية نيون.
  - تصميم متجاوب 100% لكافة الشاشات (الهواتف، الأجهزة اللوحية، الشاشات الكبيرة).

- **الواجهة الخلفية (Backend):**
  - **ASP.NET Core Web API** مبني وفق هيكلية الـ **Clean Architecture**.
  - قاعدة بيانات سريعة وآمنة عبر **Entity Framework Core (SQLite)** تعمل فورياً بدون أي تثبيتات معقدة.
  - نظام توثيق وتشفير متقدم باستخدام **JWT Bearer Authentication** وتشفير **BCrypt** لكلمات المرور.
  - واجهة توثيق وفحص تفاعلية لكافة الـ Endpoints عبر **Swagger / OpenAPI**.

---

## الهيكل والميزات المطلوبة بدقة

1. **الواجهة الترحيبية والناف بار:**
   - شعار المتجر بأنيميشن دوران وتوهج نيون مستمر.
   - زر **"لنبدأ"** التفاعلي مع تأثيرات هالة ضوئية ينقلك بسلاسة إلى الأقسام الأربعة.
   - ناف بار يحتوي على: الرئيسية، المنتجات، العروض، الميديا، وزر **تسجيل الدخول** التفاعلي.

2. **الخانات الأربع المتمركزة في المنتصف (Centered Categories):**
   - **IPhone** (أجهزة آيفون الأصلية مع Apple Official Gear).
   - **Android** (أجهزة أندرويد الرائدة: Samsung, Xiaomi, Pixel).
   - **Accessories** (السماعات، الشواحن السريعة، الكفرات الأصلية).
   - **Other** (الساعات الذكية، أجهزة الآيباد والتابلت، والإكسسوارات الذكية).

3. **آلية الطلب المباشر:**
   - **بدون سلة تسوق معقدة**، كل منتج يحتوي على زرين مباشرين:
     - **اطلب واتساب:** يفتح محادثة واتساب فورية برسالة مجهزة تلقائياً تتضمن اسم المنتج، سعره، وقسمه.
     - **اطلب بالاتصال:** يقوم بالاتصال المباشر على رقم الهاتف المحدد.

4. **نافذة التسجيل الذكي (Google / Facebook Auth Modal):**
   - عند ضغط العميل على "اطلب واتساب" أو "اطلب بالاتصال" وهو غير مسجل، تظهر له نافذة عصرية للتسجيل الفوري بحساب **Google** أو **Facebook** (أو البريد الإلكتروني).
   - بمجرد الدخول، يتم توثيق بياناته في لوحة الإدارة وإتمام طلبه تلقائياً!

5. **صفحة وقسم الميديا (Social Media Hub):**
   - بطاقات عرض مخصصة لصفحاتك الرسمية على:
     - **Facebook**
     - **Instagram**
     - **TikTok**
   - جميع الروابط ديناميكية ويتحكم فيها الأدمن حصرياً من لوحة التحكم.

6. **لوحة تحكم الإدارة (Admin Dashboard):**
   - **تبويب الإحصائيات والزوار:**
     - عداد إجمالي الزوار الفعليين للموقع.
     - عداد المستخدمين المسجلين (وطريقة دخول كل مستخدم: Google, Facebook, Local).
     - عداد نقرات طلبات الشراء وتوزيعها (واتساب مقابل اتصال هاتفي).
     - جدول تفصيلي لنقرات العملاء لمتابعة الطلبات.
   - **إدارة المنتجات:** إضافة، تعديل، وحذف أي منتج مع تصنيفه في إحدى الخانات الأربع وتحديد سعره وصورته.
   - **إدارة العروض:** نشر وتعديل العروض الترويجية والخصومات.
   - **إدارة الأرقام والسوشيال:** تحديد رقم الواتساب ورقم الاتصال، وتعديل روابط السوشيال ميديا في أي وقت وبضغطة زر.

## طريقة تشغيل واختبار المشروع

المشروع مفصول تماماً في نفس المجلد:
`H:\3mmarStore\`
- `backend/` -> ASP.NET Core Web API
- `frontend/` -> Angular Application

### 1. عبر Visual Studio (VS):
- افتح ملف الحل `3mmarStore.sln` الموجود في `H:\3mmarStore\`.
- اضغط **F5** أو زر **Start** لتشغيل الباك إند (سيعمل على `http://localhost:5000` ويوفر Swagger على `http://localhost:5000/swagger`).

### 2. عبر Visual Studio Code (VSC):
- افتح المجلد الرئيسي `H:\3mmarStore`.
- لتشغيل الباك إند عبر الطرفية:
  ```bash
  cd backend
  dotnet run --urls=http://localhost:5000
  ```
- لتشغيل الفرونت إند عبر الطرفية:
  ```bash
  cd frontend
  npx ng serve --open
  ```
- سيتم فتح الموقع تلقائياً على المتصفح: `http://localhost:4200`.
